# Отчёт: лабораторная работа №4

## Цель

Построить рекомендательную систему fashion-товаров по визуальной похожести изображений, сравнить не менее трёх методов и предоставить пользовательский интерфейс с фильтрами каталога.

## Данные и EDA

Источник — Fashion Product Images (Small): изображения `images/<id>.jpg` и файл `styles.csv`. До построения моделей `eda.py` удаляет строки без существующего изображения и формирует графики распределений `masterCategory`, `gender`, `season`, `articleType` и `baseColour`. Это позволяет увидеть дисбаланс классов и не интерпретировать частые категории как безусловное качество модели.

Команда для воспроизведения:

```powershell
python eda.py --data-dir data/fashion
```

## Модели

1. **HOG + PCA + KNN.** HOG описывает контуры и локальные градиенты изображения; PCA уменьшает размерность и убирает коррелированные компоненты; cosine KNN ищет соседей.
2. **ResNet-18 embeddings.** Последний классификационный слой предобученной ImageNet ResNet заменяется на identity, поэтому используется вектор признаков изображения, а не предсказанный ImageNet-класс.
3. **MobileNetV3 Small embeddings.** Аналогичный transfer-learning подход, но с компактной архитектурой, ориентированной на быстрый inference.

Все векторы L2-нормируются, следовательно скалярное произведение равно cosine similarity. Это делает ранжирование сопоставимым между моделями.

## Оценка и выбор модели

Пользовательских взаимодействий в датасете нет, поэтому для offline-сравнения применяется category coherence: у случайных товаров измеряется доля соседей с тем же `articleType` и `subCategory` — `Precision@K`. Запрос всегда исключается из собственной выдачи. Одинаковая выборка запросов и одинаковое `K` используются для всех трёх методов. Победитель определяется по `article_type_precision_at_k`, сохраняется в `artifacts/best_index.npz`, а полная таблица — в `artifacts/benchmark.csv`.

```powershell
python build_index.py --data-dir data/fashion --sample-size 5000
```

Численные результаты намеренно не зафиксированы в этом файле: они зависят от выбранного размера выборки, версии данных и наличия GPU. Скрипт создаёт их автоматически в версионируемом CSV.

## Интерфейс

В Streamlit пользователь выбирает товар-образец и фильтры `gender`, `masterCategory`, `season`, `usage`. После фильтрации система показывает топ похожих товаров с изображениями, метаданными и значением similarity. В отдельном блоке видны выбранная модель и таблица результатов её сравнения.
