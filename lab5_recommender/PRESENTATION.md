## 2. Алгоритмы рекомендательной системы

### 2.1 Content-Based (Рекомендирование по контенту)

#### Идея
"Если пользователю нравится фильм X с жанрами Action/Sci-Fi, рекомендуем другие фильмы с похожими жанрами и тегами"

#### Реализация

```
Шаг 1: Построение признаков
    Каждый фильм = текстовый вектор признаков
    features[i] = genres[i] + " " + tags[i]
    
    Пример: "Action Adventure", "Action Sci-Fi", "Comedy Drama"

Шаг 2: TF-IDF преобразование
    TF-IDF(фильм) = вектор[300+] (частоты слов, взвешенные по редкости)
    
    TF(слово) = кол-во вхождений слова в фильм / всего слов в фильме
    IDF(слово) = log(всего фильмов / фильмов со словом)

Шаг 3: Косинусное сходство
    similarity(фильм_i, фильм_j) = (вектор_i · вектор_j) / (|вектор_i| × |вектор_j|)
    
    Диапазон: [0, 1], где 1 = идентичные, 0 = совершенно разные

Шаг 4: Рекомендации
    Для профиля пользователя (взвешенная комбинация его оценённых фильмов):
    рекомендации = top-N фильмов по убыванию similarity с профилем
```

#### Математика профиля пользователя

```
profile = Σ(rating_i × tf_idf_i) / Σ rating_i    [без нормализации]

Центрирование (если разнообразие оценок > 0):
    weight_i = rating_i - mean(ratings)
    
    → "нелюбимые" фильмы (≤2.5) получают отрицательный вес
    → это ОТТАЛКИВАЕТ профиль от их признаков
```

### 2.2 Collaborative Filtering (Коллаборативная фильтрация)

#### Идея
"Если пользователь A и пользователь B одинаково оценивали 100 фильмов, то фильм, который нравится B, вероятно, нравится и A"

#### Реализация (Item-Based KNN)

```
Шаг 1: Построение матрицы рейтингов
    Matrix[фильм_i, пользователь_j] = rating_ij   (или 0, если не оценивал)
    
    Размер: ~9000 фильмов × ~600 пользователей

Шаг 2: Центрирование по фильмам
    Для каждой строки вычитаем среднее:
    centered[i, j] = rating[i, j] - mean_rating[i]
    
    ЗАЧЕМ?
    - Убирается "bias популярности": факт что Титаник имеет средний рейтинг 4.2
    - Остаётся ОТНОСИТЕЛЬНОЕ отношение пользователей: кому он нравится (выше среднего)

Шаг 3: Item-Item сходство
    Для каждой пары фильмов:
    similarity(фильм_i, фильм_j) = cosine(centered_row_i, centered_row_j)
    
    → Фильмы одинаково любимы одними пользователями
    → Фильмы одинаково нелюбимы одними пользователями
    → similarity высока = похожая "аудитория"

Шаг 4: Рекомендация для пользователя
    score(фильм_новый) = Σ similarity(фильм_новый, фильм_оценённый) × 
                         (rating_оценённый - 2.5)
    
    Сумма по всем оценённым фильмам!
    Сдвиг на 2.5 → низкие оценки штрафуют (отталкивают)
```

#### Математический пример

```
Матрица после центрирования (N.rows = 3 фильма, cols = 4 пользователя):

              User1  User2  User3  User4
Avatar        +1.5   +0.2   -0.8    0
Titanic        0     -1.2   +0.5   +1.0
Inception     -0.3   +0.8   +1.2   -0.5

similarity(Avatar, Titanic) = cosine([1.5, 0.2, -0.8, 0], [0, -1.2, 0.5, 1.0])
                             = (0 - 0.24 - 0.4 + 0) / (√|Avatar|² × √|Titanic|²)
                             ≈ -0.35 (отрицательное: противоположная аудитория)

Если User5 оценил Avatar на 4.5, Titanic на 2.0:
    score(Inception) = similarity(Inception, Avatar) × (4.5 - 2.5) +
                       similarity(Inception, Titanic) × (2.0 - 2.5)
                     ≈ -0.3 × 2.0 + some_sim × (-0.5)
                     
Чем сильнее оценка выше 2.5, тем больше её наибольший вес!
```

#### Код

```python
class CollaborativeRecommender:
    def __init__(self, min_ratings: int = 5):
        ratings = load_ratings()
        
        # Матрица: фильмы × пользователи
        self.pivot = ratings.pivot_table(
            index="movie_id", columns="user_id", values="rating"
        )
        
        # Центрирование
        centered = self.pivot.sub(self.pivot.mean(axis=1), axis=0).fillna(0)
        
        # Сходство
        self.sims = cosine_similarity(centered.values)
    
    def for_user(self, ratings: DataFrame) -> DataFrame:
        # ratings: [movie_id, rating]
        pred = np.zeros(len(self.movie_ids))
        
        for _, r in ratings.iterrows():
            movie_idx = self.idx_by_id[r["movie_id"]]
            # scores += similarity * (rating - 2.5)
            pred += self.sims[movie_idx] * (r["rating"] - 2.5)
        
        # Top-N по pred
        return sorted_by_pred[:top_n]
```

#### Достоинства и недостатки

| Достоинства | Недостатки |
|-------------|-----------|
| ✅ Находит неочевидные закономерности | ❌ "Холодный старт" для новых пользователей |
| ✅ Считает с данными других пользователей | ❌ "Холодный старт" для новых фильмов* |
| ✅ Объясняется через схожесть "вкусов" | ❌ Требует большого набора рейтингов |
| ✅ Избегает "фильтр-пузыря" | ❌ Может быть медленнее для больших данных |

*_Новый фильм без рейтингов не имеет строки в матрице_

### 2.3 Hybrid Recommender (Гибридная система)

#### Идея
"Content-based даёт объяснимость и работает с новыми фильмами, Collaborative находит скрытые закономерности. Объединим лучшее!"

#### Реализация

```
Шаг 1: Получить рекомендации от обоих алгоритмов (top-200 каждого)
    C = content.for_user(ratings, top_n=200)
    K = collab.for_user(ratings, top_n=200)

Шаг 2: Нормализовать оценки обоих в [0, 1]
    score_norm = (score - min) / (max - min)
    
    ЗАЧЕМ? Масштабы разные:
    - Content-based: similarity в [0, 1]
    - Collaborative: может быть в любом диапазоне (даже отрицательные)

Шаг 3: Объединить с параметром α
    hybrid_score = α × score_content + (1 - α) × score_collab
    
    α ∈ [0, 1]:
    - α = 1.0 → только content-based
    - α = 0.5 → равный вес
    - α = 0.0 → только collaborative

Шаг 4: Ранжировать и вернуть top-N
    recommendations = sorted(merged, by=hybrid_score, descending=True)[:top_n]
```

#### Примеры использования параметра α

| α | Сценарий | Применение |
|---|----------|-----------|
| 0.8 | Content-heavy | Новые пользователи (мало оценок) |
| 0.5 | Balanced | Стандартный режим |
| 0.2 | Collab-heavy | Опытные пользователи (много оценок) |

#### Код (упрощённо)

```python
class HybridRecommender:
    def __init__(self, content: ContentRecommender, collab: CollaborativeRecommender):
        self.content = content
        self.collab = collab
    
    def for_user(self, ratings: DataFrame, top_n: int = 10, alpha: float = 0.5):
        # Получить оба набора
        c = self._norm(self.content.for_user(ratings, top_n=200))
        k = self._norm(self.collab.for_user(ratings, top_n=200))
        
        # Объединить
        merged = c.merge(k, on=['movie_id', ...], how='outer', suffixes=('_c', '_k'))
        merged['score'] = alpha * merged['score_c'] + (1 - alpha) * merged['score_k']
        
        # Вернуть top-N
        return merged.nlargest(top_n, 'score')
```

#### Достоинства

✅ Одновременно объясним (content) и умён (collab)  
✅ Гибкий: можно регулировать α под сценарий  
✅ Работает и для новых, и для опытных пользователей  
✅ Уменьшает "фильтр-пузырь" коллаборативной фильтрации

### 2.4 Cold Start (Холодный старт)

#### Проблема
- **Content-based**: Может рекомендовать, но нужна хотя бы одна оценка
- **Collaborative**: Не может работать вообще (пользователя нет в матрице)
- **Новый пользователь**: У него ноль оценок!

#### Решение: Трёхуровневая автоматическая система в проекте

##### Уровень 1: Обнаружение (автоматическое)

```python
# app.py
def user_mode(u: dict):
    ml_uid = u["ml_user_id"]
    hist = auth.get_user_ratings(ml_uid)  # Получить историю оценок
    
    if hist.empty:  # ← АВТОМАТИЧЕСКОЕ ОБНАРУЖЕНИЕ ХОЛОДНОГО СТАРТА
        _cold_start(ml_uid)  # Показать форму холодного старта
    else:
        _personal_feed(ml_uid, hist)  # Обычное меню
```

**Поток пользователя:**
```
1. Пользователь регистрируется и входит
   ↓
2. Система проверяет: есть ли у него оценки?
   ↓
   НЕТ? → Показываем холодный старт
   ДА?  → Показываем персональные рекомендации
```

##### Уровень 2: Форма холодного старта (3 шага)

**Шаг 1: Выбор жанров**
```
Интерфейс: Multiselect (несколько жанров одновременно)
По умолчанию: Comedy, Adventure
Пример: [Comedy, Adventure, Action]
```

**Шаг 2: Оценка фильмов**
```
Алгоритм находит и показывает:
- top-10 фильмов с выбранными жанрами
- с высоким рейтингом и большим числом оценок
- каждый слайдер 0-5 звёзд (0 = пропустить)

Минимум: пользователь должен оценить хотя бы несколько ~5-10 фильмов
```

**Шаг 3: Сохранение и переход**
```
После нажатия кнопки "Сохранить оценки":
1. Оценки сохраняются в БД (таблица ratings)
2. Page reload (st.rerun)
3. Теперь hist НЕ пуста → пользователь видит "Персональные рекомендации"
```

##### Уровень 3: Алгоритм подбора фильмов (`cold_start_by_genres`)

```
Входные параметры:
  - genres: список выбранных жанров, например ["Action", "Adventure"]
  - top_n: сколько фильмов вернуть (обычно 10-15)
  - min_ratings: минимум оценок у фильма (обычно 30)

Шаг 1: Фильтр по жанрам
  WHERE фильм включает хотя бы один из выбранных жанров

Шаг 2: Фильтр по популярности
  WHERE COUNT(рейтинги) >= min_ratings
  (исключаем редкие фильмы с шумом)

Шаг 3: BAYESIAN RANKING (ключевой шаг!)
  
  Проблема: Fargo (100 оценок, 4.8★) vs. Masterpiece-Z (1 оценка, 5.0★)?
  
  Решение: Bayesian усреднение
  score = (n × avg + m × C) / (n + m)
  
  Где:
    n = COUNT(оценки этого фильма)
    avg = средняя оценка фильма
    m = параметр доверия (обычно ~ min_ratings = 30)
    C = глобальная средняя оценка (~3.5)
  
  Интерпретация:
    → Если n мало: score ≈ C (общая средняя)
    → Если n велико: score ≈ avg (реальная оценка)
    → m = "сколько виртуальных голосов среднего качества добавить"
  
  Примеры:
    Fargo:       score = (100 × 4.8 + 30 × 3.5) / 130 ≈ 4.65
    Masterpiece: score = (1 × 5.0 + 30 × 3.5) / 31 ≈ 3.61 ← штрафован!
    (это правильно: одна 5-звёздочка не надёжна)

Шаг 4: Штраф за недостаток жанров
  final_score = bayesian_score × (match_count / len(genres))
  
  match_count = сколько выбранных жанров имеет фильм
  len(genres) = сколько жанров выбрал пользователь
  
  Примеры:
    - Фильм только Action, выбраны [Action, Adventure] → 1/2 = 0.5× штраф
    - Фильм и Action, и Adventure → 2/2 = 1.0× (бонус!)

Шаг 5: Ранжирование и возврат top-N
  SORT by final_score DESC
  LIMIT top_n
```

#### Пример работы

```
Сценарий: Пользователь выбрал [Action, Adventure]

Фильмы в БД (отфильтрованы):
  - The Dark Knight
    - Жанры: Action, Crime, Drama
    - Оценок: 462, средняя: 4.5★
    - Совпадение: 1 из 2 жанров (Action)
    - Bayesian: (462×4.5 + 30×3.5) / 492 ≈ 4.43
    - Final: 4.43 × 1/2 = 2.215
    
  - Inception
    - Жанры: Action, Mystery, Sci-Fi
    - Оценок: 380, средняя: 4.2★
    - Совпадение: 1 из 2 жанров (Action)
    - Bayesian: (380×4.2 + 30×3.5) / 410 ≈ 4.14
    - Final: 4.14 × 1/2 = 2.07
    
  - Pirates of the Caribbean
    - Жанры: Action, Adventure, Comedy, Fantasy
    - Оценок: 320, средняя: 4.0★
    - Совпадение: 2 из 2 жанров (Action + Adventure!)
    - Bayesian: (320×4.0 + 30×3.5) / 350 ≈ 3.95
    - Final: 3.95 × 2/2 = 3.95 ← ЛУЧШИЙ!

Результат:
  1. Pirates of the Caribbean (3.95)
  2. The Dark Knight (2.215)
  ...
```

#### Почему именно Bayesian, а не простая средняя?

| Метрика | "5-звёздочка" (1 оценка) | "4.3 звезды" (100 оценок) | Правильно? |
|---------|------------------------|-----------------------|-----------|
| Простая средняя | 5.0 | 4.3 | ❌ Ранжирует шумную оценку выше |
| Bayesian (m=30) | 3.61 | 4.24 | ✅ Скромнее к шуму |

### 2.5 Оценка моделей (Evaluation)

#### Метод: Leave-Last-K-Out

```
Идея: эмулировать реальный сценарий

Для каждого пользователя (с ≥30 оценок):
  1. Сортировать его оценки по timestamp_value (от старых к новым)
  2. Последние K оценок = TEST SET
  3. Остальные = TRAIN SET
  4. Переобучить collaborative прямо на TRAIN (БЕЗ информации о TEST!)
  5. Получить рекомендации, проверить hit rate

Пример:
  History: [A(2020), B(2021), C(2022), D(2023), E(2024)]
           └─────────────TRAIN──────┘  └──TEST─┘ (K=2)
```

#### Метрики

- **Precision@N**: из N рекомендаций, сколько релевантны? (rating ≥ 4)
- **Recall@N**: из всех релевантных фильмов, сколько в top-N?
- **F1@N**: гармоническое среднее (баланс precision/recall)

## 4. Заключение

Проект демонстрирует **полный производственный цикл** рекомендательной системы:

| Компонент | Назначение | Алгоритм |
|-----------|-----------|----------|
| **Content-Based** | Понимание фильмов | TF-IDF + Cosine |
| **Collaborative** | Поиск закономерностей | Item-Item KNN |
| **Hybrid** | Объединение обоих | α-блендинг |
| **Cold Start** | Вход новых пользователей | Bayesian ranking |
| **Evaluation** | Валидация качества | Leave-Last-K-Out |

**Ключевая особенность:** Система **автоматически** выбирает правильный алгоритм в зависимости от статуса пользователя:
- Новичок → **Cold Start** → Hybrid (после оценок)
- Опытный → **Hybrid** (с отрицательным или content-heavy α)

**Стек:** Python → Streamlit → scikit-learn → SQLite (простота + производительность)
