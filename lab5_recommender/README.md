# Movie Recommender — лабораторные работы №5–6

Веб-приложение для рекомендаций фильмов на Python и Streamlit. Проект показывает полный путь от CSV-датасета до пользовательского интерфейса: нормализация данных в SQLite, несколько рекомендательных алгоритмов, обработка cold start и offline-оценка качества.

## Возможности

- **Content-based filtering:** TF-IDF по жанрам и пользовательским тегам, косинусная близость.
- **Collaborative filtering:** item-to-item рекомендации по матрице оценок с центрированием.
- **Гибридная модель:** объединение нормализованных content- и collaborative-скоров с регулируемым весом.
- **Cold start:** жанровый онбординг и Bayesian-ранжирование популярных фильмов.
- **Оценка качества:** leave-last-K-out без утечки тестовых оценок; Precision@N, Recall@N и F1@N.
- **Интерфейс Streamlit:** регистрация, личная лента рекомендаций и административный режим для демонстрации алгоритмов.

## Стек

Python 3.10+ · Streamlit · pandas · NumPy · scikit-learn · SQLite · MovieLens 100K

## Запуск

Из папки `lab5_recommender`:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python etl.py
streamlit run app.py
```

Команда `etl.py` создаёт `movies.db` из CSV-файлов в `data/`. База намеренно не хранится в Git: приложение добавляет в неё аккаунты и пользовательские оценки, а данные можно детерминированно пересобрать.

После запуска откройте адрес, который выведет Streamlit. Для демонстрации административного режима используется аккаунт `admin` / `admin`; это учебная учётная запись, не предназначенная для реального сервиса.

## Структура

```text
lab5_recommender/
├── app.py              # Streamlit-интерфейс и сценарии пользователя/админа
├── auth.py             # локальная регистрация, вход и сохранение оценок
├── recommender.py      # content-based, collaborative, hybrid, cold start, evaluation
├── etl.py              # загрузка CSV и нормализация в SQLite
├── schema.sql          # схема и индексы базы данных
├── data/               # компактный датасет MovieLens для воспроизводимого запуска
├── requirements.txt    # зависимости приложения
├── REPORT.md           # подробный отчёт по лабораторной работе №5
└── PRESENTATION.md     # сценарий и материалы для презентации
```

## Данные

В проект включён поднабор [MovieLens](https://grouplens.org/datasets/movielens/) с фильмами, оценками, тегами и внешними идентификаторами. Исходные CSV в `data/` служат источником истины; при необходимости достаточно повторно запустить `python etl.py`.
